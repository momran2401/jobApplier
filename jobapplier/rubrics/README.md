# Resume rubrics

`software_engineering_intern/` is copied verbatim from HackerRank's open-source resume scorer,
[interviewstreet/hiring-agent](https://github.com/interviewstreet/hiring-agent) (MIT License, Copyright (c) 2025
HackerRank; see `LICENSE-hiring-agent`), commit e0ece80 (2026-10-05). `jobapplier/match.py` renders these files
the way hiring-agent does (categories, caps, bonus rules and bonus validation), with this app's own model
plumbing and a deterministic keyword-coverage check added alongside.
